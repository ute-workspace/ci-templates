# Implementation Pass

Stage summary. The procedure is the `implementation-pass` skill;
folder rules are `core/standards/features.md`.

## Purpose

Implement an approved feature folder test-first, keep `plan.md` current,
and close the feature once the audit passes.

## Rules

- Re-check scope tags against the code before changing it.
- Every behavior change starts with a failing test.
- Follow existing project conventions even if imperfect.
- Do not broaden scope without noting it.
- Do not run destructive commands or deploy unless explicitly requested.
- Do not hide failed checks.
